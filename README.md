# ExploreKZ

A responsive travel-planning prototype for Kazakhstan. It is a static HTML, CSS and JavaScript site that can be hosted on GitHub Pages from the repository root.

The destination catalog and saved packing list work in the browser. Current temperature is requested from Open-Meteo; a manual temperature control is available if the service cannot be reached. Saved items stay in browser local storage.

The site is a student prototype, not an official travel or emergency information service. Photo authors and licenses are listed in the site footer and `photos/credits.json`.
